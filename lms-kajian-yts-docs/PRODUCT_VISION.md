# Product Vision

## Nama Produk

LMS Kajian Ustadz Abu Haidar As-Sundawy

## Pemilik Produk

Yayasan Tarbiyah Sunnah

## Visi

Menjadi aplikasi web pembelajaran kajian yang terstruktur, mudah digunakan, aman, dan terhubung dengan kajian offline, sehingga jamaah dapat menemukan jadwal, menghadiri kajian, melakukan murajaah, membaca transkrip PDF, dan mengukur pemahaman secara berkelanjutan.

## Bentuk Produk

Aplikasi web responsif dengan:

- Desktop view
- Mobile view
- Tablet support
- PWA-ready pada fase lanjutan

## Nilai Utama

- Memudahkan jamaah menemukan kajian.
- Memudahkan murajaah.
- Menyatukan video, transkrip, ringkasan, dan kuis.
- Menjaga dokumentasi kajian.
- Memberikan data evaluasi kepada YTS.

## Posisi Produk

Produk ini bukan:

- Pengganti majelis ilmu.
- Platform video biasa.
- Arsip YouTube semata.
- Aplikasi mobile native pada fase awal.

Produk ini adalah:

> Aplikasi web pendamping kajian offline dan digital YTS.
