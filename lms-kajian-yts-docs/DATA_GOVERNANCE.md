# Data Governance

## Principles

- Data minimization
- Purpose limitation
- Access control
- Auditability
- User consent
- Retention policy

## Sensitive Data

Jangan kumpulkan data yang tidak dibutuhkan.

## Participant Notes

Catatan pribadi tidak dibagikan ke CRM dan tidak dibaca admin secara default.

## CRM Sharing

Hanya data dasar, enrollment, attendance, dan consent yang dapat dibagikan sesuai kebijakan.
