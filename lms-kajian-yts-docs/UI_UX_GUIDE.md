# UI/UX Guide

## Bentuk Produk

Aplikasi web responsif dengan desktop view dan mobile view.

## Desktop View

Digunakan terutama untuk:

- Admin
- Reviewer
- Operator
- Analyst

Pola layout:

- Sidebar
- Topbar
- Breadcrumb
- Content area
- Data table
- Filter
- Drawer atau modal
- Detail panel

## Mobile View

Digunakan terutama oleh peserta.

Pola layout:

- Bottom navigation
- Header ringkas
- Card sederhana
- Tab horizontal
- Sticky action
- Konten satu kolom

## Navigasi Mobile

- Beranda
- Kajian Saya
- Jadwal
- Tersimpan
- Akun

## Halaman Belajar Mobile

1. Judul
2. Video
3. Progres
4. Tab
5. Ringkasan atau PDF
6. Kuis
7. Sebelumnya/Berikutnya

## Halaman Belajar Desktop

- Video kiri
- Daftar pertemuan kanan
- Tab materi di bawah
- Navigasi lesson
- Progres program

## Prinsip

- Mobile-first
- Desktop-optimized for admin
- Fokus pada ilmu
- Tidak berlebihan
- Font terbaca
- Kontras baik
- Error jelas
- Empty state
- Loading state
- Responsive breakpoint yang konsisten

## Breakpoint

- Mobile: < 768px
- Tablet: 768–1023px
- Desktop: >= 1024px
- Wide desktop: >= 1440px
