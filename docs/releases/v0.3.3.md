# v0.3.3 — Perbaikan deploy konfigurasi S3 publik

Log produksi 6ada0776644cdefd19024894 menunjukkan build Vite dan bundling Functions berhasil. Deploy kemudian dihentikan karena secret scanner mencocokkan nilai S3_BUCKET (nama bucket publik), termasuk pada dokumentasi dan nama repository.

Perubahan ini menambahkan hanya S3_BUCKET, S3_ENDPOINT, S3_REGION, dan S3_PUBLIC_URL ke allowlist SECRETS_SCAN_OMIT_KEYS yang sudah berisi BETTER_AUTH_URL. Pemindaian tetap aktif untuk seluruh repository/build output dan semua kredensial, termasuk S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY, DATABASE_URL dan OAuth secret.

Tes konfigurasi memeriksa allowlist yang eksplisit dan memastikan credential keys tidak dikecualikan. Tidak ada perubahan runtime, migrasi otomatis, upload objek, atau aktivasi PDF privat/revisi dalam hotfix ini. Pengembangan unggah Contabo/sampul program belum disertakan.

Migrasi database yang disetujui pengguna dan telah dijalankan secara terpisah dicatat pada dokumen pengembangan Contabo; hotfix ini sendiri tidak menjalankan migrasi.
