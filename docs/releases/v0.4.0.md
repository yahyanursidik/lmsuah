# Rilis v0.4.0 unggah media dan PDF privat

Paket ini menambahkan unggah foto langsung, sampul Program Kajian, PDF publik dan adapter PDF privat Contabo yang terpisah. Publikasi kode tidak mengaktifkan fitur PDF privat atau revisi produksi secara otomatis.

## Fitur

- Pilih JPEG, PNG atau WebP dari perangkat untuk sampul program, lokasi dan pengumuman. Server membatasi 4 MiB, memvalidasi isi, menghapus metadata dan mengoptimalkan foto menjadi WebP.
- Pratinjau, indikator unggah dan pesan gagal tersedia; formulir tidak dapat disimpan saat unggah berjalan. Gambar lama dipertahankan bila unggah gagal.
- Materi PDF publik dapat diunggah dengan konfirmasi bahwa dokumen boleh diakses publik.
- PDF privat baru dapat memakai lmsuahprivate dengan ACL private, nama versi unik, pencegahan penimpaan dan pemeriksaan penolakan akses anonim sebelum metadata disimpan.
- Kunci Netlify lama tetap dibaca dari penyimpanan lama. Bucket publik lmsuah tetap dilarang untuk PDF privat.
- Secret scanner Netlify hanya mengecualikan metadata bucket, endpoint, provider dan flag boolean yang bukan secret. Kredensial, database dan OAuth secret tetap dipindai.
- Endpoint /api/health mengambil versi dari package.json; tes menjaga konsistensi versi API, paket dan lock.
- Pesan fitur privat yang belum aktif menjelaskan pilihan penyimpanan dan kebutuhan izin, tanpa keliru menyatakan migrasi pasti belum dijalankan.

## Pengujian

E2E browser nyata pada salinan database mencakup login tiga akun sintetis; pilih foto, indikator proses, pratinjau, simpan program, tampil publik dan peserta; serta gambar rusak yang menampilkan error tanpa menghapus sampul lama.

Alur PDF mencakup unggah draft, larangan persetujuan oleh pengunggah, persetujuan reviewer berbeda, publikasi, penolakan tamu/peserta tanpa izin, pembacaan peserta berizin dengan hash identik, HTTP range 206, penolakan unduh dan unggah yang tidak diizinkan, serta mode layar penuh. Native PDF benar-benar dirender dan screenshot desktop/mobile diperiksa; halaman peserta tidak logout atau mengalami overflow horizontal.

Run akhir menggunakan tiga akun, satu role pembaca sementara dan dua objek storage sintetis. Seluruhnya dibersihkan; jumlah baris salinan kembali seperti sebelum tes. Tidak ada penulisan ke database sumber, perubahan policy bucket atau pemberian izin role produksi.

Seluruh 419 tes regresi/57 file, lint, TypeScript dan build produksi diverifikasi sebelum merge. Perintah ulang:

```
npm ci
npx playwright install chromium
npm run test:e2e:media
```

LMS_E2E_ENV_FILE dapat menunjuk .env lokal dari worktree. Skrip memerlukan manifest salinan yang disetujui, menolak database sumber, memakai port 5182 yang kosong, dan mengaktifkan PDF privat hanya pada proses server salinan. Screenshot disimpan di test-results/media-e2e/ dan tidak dikomit.

## Database dan aktivasi produksi

Migrasi 0010–0014 telah diterapkan atomik pada produksi dengan persetujuan setelah uji salinan lulus: 15 entri journal, tanpa schema drift atau perubahan baris aplikasi. Adapter privat tidak memerlukan migrasi tambahan; build/deploy tidak menjalankan migrasi.

Konfigurasi server privat:

```env
CONTABO_PRIVATE_BUCKET=lmsuahprivate
CONTABO_PRIVATE_ENDPOINT=https://sin1.contabostorage.com
LMS_PRIVATE_PDF_STORAGE=contabo
```

Kredensial memakai pasangan S3_ACCESS_KEY_ID/S3_SECRET_ACCESS_KEY atau CONTABO_ACCESS_KEY_ID/CONTABO_SECRET_ACCESS_KEY yang lengkap, tanpa dicampur. S3_BUCKET publik tetap lmsuah. Jangan mengirim secret ke browser atau Git.

LMS_PRIVATE_PDF_ENABLED dan LMS_PROGRAM_REVISIONS_ENABLED tidak diubah oleh rilis. Pembaca PDF memerlukan transcript.read. Pada salinan uji, role participant belum memiliki izin ini; pengujian memakai role sementara khusus akun sintetis, bukan mengubah role participant. Tinjau pemetaan izin produksi sebelum aktivasi terpisah.

## Catatan pemeliharaan

Audit npm masih melaporkan 13 temuan dependensi lama, termasuk dua critical. Temuan tidak berasal dari Playwright yang ditambahkan untuk E2E. Pembaruan breaking/force pada toolchain tidak dilakukan dalam rilis ini dan memerlukan pekerjaan hardening tersendiri.
