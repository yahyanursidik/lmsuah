# Acceptance Criteria

## Web Responsiveness

- Semua halaman dapat digunakan di desktop dan mobile.
- Tidak ada horizontal overflow pada mobile.
- Admin table tetap usable di desktop.
- Peserta dapat belajar melalui ponsel.

## Auth

- Login Google bekerja.
- CAPTCHA aktif.
- Session tersimpan.
- Redirect aman.

## PDF

- Hanya PDF valid.
- Draft tidak terlihat.
- Viewer mobile bekerja.
- Authenticated file endpoint kedaluwarsa.
- Izin unduh dipatuhi.

## Quiz

- Attempt tercatat.
- Score dihitung server.
- Jawaban benar terlindungi.
- Result hanya milik peserta.

## Security

- RLS aktif.
- Database administrator credential tidak ada di bundle.
- Notes privat.
- Audit tercatat.
