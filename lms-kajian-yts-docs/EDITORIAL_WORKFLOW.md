# Editorial Workflow

## Status

- Draft
- Submitted for Review
- In Review
- Revision Requested
- Approved
- Scheduled
- Published
- Archived

## Roles

- Contributor
- Reviewer
- Publisher

## Checklist Lesson

- Program benar
- Seri benar
- Nomor pertemuan benar
- Judul benar
- Video dapat diputar
- Ringkasan diperiksa
- Timestamp benar
- PDF dapat dibuka
- Versi PDF benar
- Kuis diperiksa
- Access type benar

## Audit

Setiap publish, unpublish, archive, dan replace dicatat.
