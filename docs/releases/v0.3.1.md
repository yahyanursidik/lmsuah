# v0.3.1 — Footer bantuan dan tautan live Tarbiyah Sunnah Channel

Rilis patch dari v0.3.0, 22 Oktober 2026.

## Perubahan

- Footer menjelaskan bantuan untuk kendala, error atau kegagalan sistem melalui `ahlan@yahyanursidik.my.id`, dengan profil Yahya Nursidik dan jabatan Special Advisor for Digital Transformation, Innovation & Business YTS.
- Jadwal publik dan peserta menampilkan Tarbiyah Sunnah Channel sebagai kanal siaran, menggantikan label Radio Rodja.
- Admin → Jadwal & Agenda → Tambah/Edit → Siaran Langsung menyediakan:
  - Otomatis daftar siaran: `https://www.youtube.com/@TarbiyahSunnahChannel/streams`.
  - Otomatis live: `https://www.youtube.com/tarbiyahsunnahchannel/live`.
  - Manual: tautan video/siaran khusus yang dapat diisi sendiri.
- Form menyediakan pratinjau, URL otomatis read-only, validasi HTTP/HTTPS dan pesan kesalahan. Draf URL manual tidak hilang saat berpindah mode; URL tersimpan tetap dipertahankan ketika siaran dinonaktifkan.
- Handle default lama dikoreksi di pembaca/editor tanpa menimpa video/channel khusus. URL berbahaya, siaran nonaktif dan agenda dibatalkan tidak menghasilkan tombol tonton.

## Batas rilis dan verifikasi

- Tidak ada schema/migrasi, pembaruan massal jadwal, perubahan credential, atau aktivasi revisi/PDF privat produksi.
- Tes menggunakan fixture dan memeriksa footer, penyimpanan kedua mode otomatis/manual, pengeditan jadwal lama, pembatasan akses dan keamanan URL. UI diuji melalui tes komponen; pemeriksaan visual browser interaktif belum tersedia pada tahap pengembangan.
- Lint, build/TypeScript, regresi penuh dan bundling fungsi jadwal diperiksa sebelum push. Smoke test deploy preview dan produksi menggunakan GET anonim, tanpa menyimpan data jadwal nyata.
- Hasil paket rilis: **323 tes / 46 file lulus**, lint **0 error / 0 warning**, build produksi tanpa warning ukuran bundle, dan bundling handler jadwal tanpa error/warning. Regresi dijalankan ulang terpisah dari build dengan satu worker untuk menghindari batas memori Windows; tidak ada assertion yang dilonggarkan atau aturan lint yang dinonaktifkan.
