# Responsive Requirements

## Objective

Memastikan aplikasi web berfungsi baik pada desktop dan mobile.

## Mobile

- Single-column layout
- Bottom navigation
- Sticky primary actions
- Responsive video
- PDF viewer optimized
- Touch target minimum 44px
- No horizontal scroll

## Desktop

- Sidebar
- Multi-column layout
- Data table
- Filter panel
- Review workspace
- Analytics dashboard

## Required Screens

- 360x800
- 390x844
- 768x1024
- 1366x768
- 1440x900
