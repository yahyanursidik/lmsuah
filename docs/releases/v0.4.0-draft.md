# Kandidat v0.4.0 — unggah Contabo dan sampul program

Belum dirilis. PR #15 tetap draft sampai verifikasi visual end-to-end sampul selesai. Bucket privat terpisah sudah diterima dan lulus uji nyata; tidak ada tag v0.4.0 yang diterbitkan.

## Cakupan

- Unggah JPEG/PNG/WebP langsung untuk sampul program, lokasi dan pengumuman; PDF publik melalui editor materi dengan konfirmasi.
- Validasi ukuran/MIME/decode server, WebP tanpa metadata, UUID, pembatasan role/origin, pratinjau, indikator proses dan error yang jelas.
- Sampul ikut snapshot revisi; snapshot lama serta database sebelum kolom cover_image tetap dapat dibaca.
- PDF privat baru dapat memakai bucket lmsuahprivate dengan provider contabo secara opt-in. Kunci contabo-private-v1 terpisah dari key publik dan key Netlify lama.
- ACL private, cache no-store, conditional create-only dan pemeriksaan penolakan anonim sebelum metadata versi disimpan. Jika privasi gagal, hanya objek baru yang dibersihkan; kegagalan cleanup dilaporkan.
- Bucket publik lmsuah tetap diblokir untuk PDF privat, termasuk jalur contabo/ lama. Tidak memindahkan dokumen lama atau mengaktifkan feature flags.

## Bukti pengujian 22 Oktober 2026

- Seluruh 418 tes / 56 file lulus; lint 0 error/0 warning; typecheck dan build produksi lulus.
