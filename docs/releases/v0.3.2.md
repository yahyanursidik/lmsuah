# v0.3.2 — Keandalan gambar lintas portal

Tanggal rilis: 22 Oktober 2026 (Asia/Jakarta). Jenis rilis: patch (Semantic Versioning).

## Perbaikan

- Memperbaiki nama file gambar beranda yang tidak tersedia. Server sebelumnya mengembalikan HTML fallback SPA dengan status 200, sehingga gambar tetap gagal walaupun status terlihat berhasil.
- Menyatukan seluruh penampil gambar pada `AppImage`: URL dinormalisasi, fallback dicoba secara terbatas, kegagalan tidak meninggalkan ikon gambar rusak, dan gambar di-reset saat sumber/akun berubah.
- Memprioritaskan foto khusus lokasi. Pemetaan foto bawaan mengenali Umar bin Khattab serta ejaan Ukhuwah/Ukhuwwah; lokasi lain tanpa foto mendapat placeholder, bukan foto masjid lain.
- Menambahkan input/pratinjau foto di admin lokasi dan pratinjau foto pengumuman. Form menampilkan kesalahan format maupun simpan tanpa menghapus isian.
- Memakai validasi URL bersama pada frontend dan API lokasi/pengumuman. Menolak script/file/data URL dan URL berkredensial; server tidak mengambil URL arbitrer.
- Memakai lazy loading untuk gambar konten dan mempertahankan eager loading pada logo serta gambar utama profil/detail.

## Batas data dan operasional

- Tidak ada migrasi atau pembaruan foto massal. Tabel/API foto lokasi yang sudah ada digunakan kembali.
- Foto yang belum tersedia perlu diisi admin dengan tautan gambar yang dapat diakses browser. Placeholder bukan pengganti foto asli. Pengelolaan sampul program khusus memerlukan fitur/schema terpisah dan tidak ditambahkan dalam rilis patch ini.
- Tidak mengubah secret, konfigurasi Google OAuth, role, atau flag revisi/PDF privat. Build tidak menjalankan migrasi database.
- Uji simpan memakai database mock; pemeriksaan layanan asli hanya GET. Tidak ada penulisan data produksi untuk verifikasi.

## Verifikasi

- Workspace pengembangan: 376 tes dalam 50 file lulus, lint 0 error/0 warning, TypeScript/build produksi lulus, bundling fungsi `venues` dan `announcements` tanpa warning.
- GET localhost memverifikasi halaman/modul baru dan ketiga JPEG bawaan. Hash aset di `dist` sesuai dengan `public`.
- Pemeriksaan visual browser otomatis belum terkonfirmasi karena timeout akses browser. Perilaku tampilan, fallback, form, dan payload simpan diuji lewat komponen React dan handler API.
- Paket rilis terisolasi v0.3.2: **376 tes / 50 file lulus** (137,93 detik, satu worker), lint 0 error/0 warning, TypeScript/build produksi dan bundling kedua fungsi terkait lulus. Ketiga JPEG hasil build memiliki hash yang sama dengan aset sumber.
- Deploy preview Netlify harus lulus sebelum merge. Status deploy dan smoke GET aktual dilaporkan pada PR/hasil rilis; pemeriksaan tersebut tidak menulis data produksi.

## Rollback

Jika regresi terjadi, deploy ulang tag `v0.3.1` atau revert PR rilis ini. Tidak diperlukan rollback database karena tidak ada perubahan schema atau migrasi.
