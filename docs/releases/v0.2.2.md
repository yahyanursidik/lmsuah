# v0.2.2 — Loading portal dan jadwal kajian

Rilis patch dari v0.2.1 untuk mengurangi pengambilan data berulang dan memperjelas hasil operasi pada portal admin maupun peserta.

## Ringkasan

- Cache navigasi 30 detik, dibersihkan saat login/logout dan diperbarui setelah mutasi.
- Request identitas/izin digabung ketika berjalan bersamaan.
- Pembacaan materi dan kuis paralel; jawaban kuis tidak dikirim melalui detail pertemuan kepada pembaca umum/peserta.
- Jadwal umum tanpa program dapat dibuat, relasi program dapat dilepas, dan klik simpan berulang dicegah.
- Pesan loading, validasi, kegagalan server, timeout, dan coba lagi diperjelas; isian jadwal dipertahankan ketika gagal.
- Bundle halaman dan dependency dipisahkan untuk caching; aturan peringatan build tetap aktif.

## Verifikasi

- Dependency dipasang dari lockfile pada worktree rilis terpisah.
- Seluruh 162 tes dalam 26 file lulus pada paket rilis; lint 0 error/0 warning; typecheck/build produksi dan pemeriksaan diff lulus. Tidak ada peringatan ukuran bundle.
- Tes handler penyimpanan menggunakan database mock, tanpa perubahan data produksi.

## Di luar rilis ini

Pengembangan Program Kajian lanjutan dan migrasi 0010–0012 tidak disertakan. Sinkronisasi belajar server lanjutan, progres baru, wizard/referensi program, revisi terpisah, serta PDF privat/transkrip tetap di workspace pengembangan.

Merge tidak memerlukan migrasi atau perubahan kredensial. Status deploy dan hasil smoke test produksi dilaporkan terpisah setelah merge. OAuth akun nyata tidak diklaim terverifikasi melalui tes lokal.
